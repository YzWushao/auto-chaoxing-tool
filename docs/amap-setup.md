# 高德地图申请与配置

默认免费地图无需 Key。这些步骤只适用于主动选择高德地图的用户；本项目不会替你注册、认证、购买服务或同意平台条款。

1. 登录 [高德开放平台控制台](https://console.amap.com/)，按当前页面完成开发者注册及所需认证。
2. 在“应用管理 → 我的应用”创建应用，名称可用 `auto-chaoxing-tool`。
3. 在应用下“添加 Key”，服务平台选择 **Web 端（JS API）**，不要选择 Web 服务、Android 或 iOS。
4. 保存后获取 Key 及配套安全密钥 `securityJsCode`。按平台提示设置域名 / 站点白名单；本机访问所用地址为 `127.0.0.1` 或 `localhost`，如果填写格式不符，以高德控制台校验提示为准。不要为了排错长期开放不必要的站点。
5. 在本项目“设置 → 地图服务”填写这两项并保存，无需发到聊天、GitHub 或点位 JSON 文件中。保持默认“免费地图”也可以先保存高德凭据，随后在具体选点窗口切换高德。
6. 打开“设置 → 预设点位”，在学校下新增 / 编辑点位，地图来源选择“高德地图”；尝试拖图和搜索一个公开学校名称。确认底图、搜索、坐标回填均正常。

官方说明：[准备与申请 Key](https://lbs.amap.com/api/javascript-api-v2/prerequisites)、[安全密钥代理方式](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)、[地点搜索](https://lbs.amap.com/api/javascript-api-v2/guide/services/autocomplete)。本文依据 2026-10-24 可见的官方文档；注册、认证、额度、收费和许可规则以你当时的控制台及平台协议为准，不承诺个人额度或商业使用永久免费。

## 存储与安全

地图设置独立加密保存在本机 SQLite 中。Web JS Key 为浏览器 SDK 正常请求所需，可能在开发者工具中看到；安全密钥保留在服务器，由已登录管理员才能访问的固定路径代理添加。主控制台不执行高德脚本；地图 SDK 仅在独立同源地图页面按需加载。

点位的 JSON 导入 / 导出只包含学校与点位，不包含这两项凭据。若怀疑泄露，请先在高德控制台处置旧 Key，再更新本项目配置。

## 常见问题

- “尚未配置高德”：需要配套填写 JS Key 和 securityJsCode；也可直接切回免费地图。
- 白名单 / `INVALID_USER_DOMAIN`：核对实际访问域名是否允许，`localhost` 与 `127.0.0.1` 不一定可互换；高德服务请求由本项目传递当前站点来源。
- Key 类型 / 安全密钥错误：确认是 Web 端（JS API），两个值属于同一个 Key，不要混用 Web 服务 Key。
- 配额、认证或许可不足：到高德控制台查看，不要把地图能加载理解为其他服务都有无限额度。
- SDK / 搜索加载超时：检查网络、代理和浏览器控制台；此版本没有真实 Key 时仅能验证接入与错误分支，配置有效 Key 后才能完成真实服务验收。
- 切换地图后偏移：不要把 BD-09、GCJ-02、WGS84 数字直接混用。已有点位保留自身坐标系，工具会转换地图显示；公开转换算法仍可能有误差，保存 6 位小数不等于实地分米精度。
